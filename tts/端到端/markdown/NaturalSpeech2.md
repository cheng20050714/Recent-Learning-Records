==基于扩散模型的语音合成==
### 1. **title** && **abstract**
**核心问题**
- 这篇论文的核心目标，是解决大规模零样本文本转语音中 **“离散 codec token + 自回归语言模型”** 路线带来的三类问题：序列过长、生成不稳定、音质与细节受损。
	- [i] 诸如AudioLM、VALL-E等工作受限于文本大模型（LLM）的成功路径，倾向于将音频强制离散化以适配语言模型
- 作者提出用 **“连续潜变量 + 潜空间非自回归扩散模型 + 语音提示式 in-context learning”** 替代离散 token 自回归生成。

**解决方法**
- 现有大规模 TTS 系统多把语音量化为离散 token，再逐个 token 生成，因此容易出现韵律不稳、跳词/重复和音质较差。
- NaturalSpeech 2 的做法是先用神经音频 codec 得到量化潜向量，再用扩散模型在文本条件下生成这些潜向量；同时引入 speech prompting 增强零样本能力。

**实验结果**
- 模型在4.4万小时的数据上进行训练，在零样本（Zero-shot）语音和歌唱合成中表现出超越现有系统的音质、韵律相似度和鲁棒性。

### 2. **intro**
>[!Question]
>当前基于“离散词元+ 自回归语言模型”的大规模TTS系统存在两个根本缺陷：
>1. **生成鲁棒性差**：自回归模型长序列生成易引发误差累积，导致合成语音出现漏词、重复或崩溃。
>2. **编解码器与语言模型的“两难困境”**：单Token量化保真度低（丢失高频细节）；多残差Token（RVQ）量化保真度高，但会导致序列长度成倍增加，极大地增加了自回归模型的预测难度。

  
>[!information]
>- **Continuous Vectors（连续向量）**：NaturalSpeech 2 采用的声学表征形式。它不强制音频离散化，因此能在较低压缩率下保留细粒度声学信息，且不增加序列长度。
>- **Latent Diffusion Model（潜在扩散模型）**：一种非自回归的生成模型，通过逐步去噪的方式，将随机噪声转化为有意义的连续潜向量。
>- **In-Context Learning（上下文学习/语音提示）**：仅需提供一段极短的目标语音片段（Prompt），无需重新训练或微调模型，就能让模型模仿出该语音的音色、韵律甚至风格。


1. **音频编码（Audio Codec）**：先训练一个神经音频编解码器，将真实语音波形转换为连续的潜向量（Latent Vectors）。
2. **扩散生成（Diffusion Model）**：训练潜在扩散模型。以前置模块（音素编码器、时长预测器、基频预测器）的输出为条件，将输入的文本映射/生成为上述的连续潜向量。
3. **推理阶段（Inference）**：输入一段文本和一段短参考语音，扩散模型生成目标潜向量，编解码器将其还原为最终的高质量波形

### **3. background**
1. **TTS发展的范式转移（2.1）**：语音合成正在经历从“小数据单人高质量”向“大数据多人高多样性”的转变。为了处理海量数据，前人尝试引入语言模型的机制，但陷入了困境。
    
2. **音频编解码器的局限（2.2）**：现有的编解码器（如SoundStream, Encodec）最初是为**音频压缩与传输**设计的，追求极低比特率（Low Bitrate）。如果将它们用作**音频生成**的中间表征，就会面临 Table 2 中的两难困境。
    
3. **生成模型的优劣对比（2.3）**：自回归模型（AR）虽然在文本生成（GPT）上大获成功，但对“序列长度”极其敏感；而扩散模型（Diffusion）采用迭代去噪和非自回归生成，结合严格的单调对齐（时长预测），天生免疫长序列带来的鲁棒性问题。

### **4. method**
- NaturalSpeech 2 的三大核心模块设计：**连续向量神经音频编解码器（Neural Audio Codec）、非自回归潜在扩散模型（Latent Diffusion Model），以及用于零样本学习的语音提示机制（Speech Prompting）**。

**模块一：基于连续向量的音频编解码器 (Section 3.1)**  
*   **流程与公式 (Eq 1)**：
    *   `编码`：$h = f_{enc}(x)$。输入语音波形 $x$，通过编码器 $f_{enc}$ 提取出帧级别的隐藏序列 $h$。
    *   `残差量化 (RVQ)`：$z^i = \sum_{j=1}^R e_j^i$。对每一帧 $h^i$，通过 $R$ 个残差量化器。每个量化器输出一个码本向量 $e_j^i$。将这 $R$ 个向量**直接相加**，得到该帧的连续潜向量 $z^i$。
    *   `解码`：$x = f_{dec}(z)$。解码器将连续向量序列 $z$ 还原为波形。
		* [!] **whyRVQ?** : 虽然使用了离散的RVQ，但输出的是它们的**加和（连续向量）**。之所以保留量化器，一方面是为了只存码本ID以**节省显存**，另一方面是为了在扩散模型训练时提供额外的**正则化约束**。

**模块二：非自回归潜在扩散模型 (Section 3.2)**  
*   **基本原理**：基于随机微分方程（SDE），将目标向量 $z_0$ 加噪为纯噪声，再训练神经网络从中去噪还原。条件 $c$ 来自先验模型（音素编码器 + 时长/基频预测器）。

[DDPM模型解析](https://www.bilibili.com/video/BV16ZsPz4ECF?spm_id_from=333.788.videopod.sections&vd_source=a99ca0f9acb7c542b9d10a0bcc1917e2)

*   **核心公式解1析**：
    *   **前向加噪过程 (Eq 2)**：$dz_t = -\frac{1}{2}\beta_t z_t dt + \sqrt{\beta_t}dw_t$。
	    * 随着时间 $t \in[0,1]$ 推进，向数据 $z_t$ 中不断注入标准布朗运动噪声 $dw_t$，$\beta_t$ 控制噪声添加的速度。
    *   **逆向去噪过程 (Eq 4/5)**：可以通过求解逆向SDE或常微分方程ODE$dz_t = -\frac{1}{2}(z_t + \nabla \log p_t(z_t))\beta_t dt$  来还原数据。
	    * 这里的关键是需要知道“分数（Score）”，即对数概率密度的梯度 $\nabla \log p_t(z_t)$。
    *   **网络预测目标**：作者发现，让神经网络 $s_\theta(z_t, t, c)$ 直接预测**干净的数据 $\hat{z}_0$**，比直接预测“分数”效果更好。
*   **损失函数 (Eq 6)**：$\mathcal{L}_{diff} = \mathbb{E}[||\hat{z}_0 - z_0||^2_2 + \dots + \lambda_{ce-rvq}\mathcal{L}_{ce-rvq}]$。
	* 不仅包含预测数据 $\hat{z}_0$ 的 L2 损失，还创新性地加入了一个离散分类交叉熵损失 $\mathcal{L}_{ce-rvq}$（促使预测的连续向量向真实的RVQ码本特征靠拢）。

**模块三：用于上下文学习的语音提示机制 (Section 3.3)**  
*   **提取提示**：训练时，从目标语音 $z$ 中随机切一段 $z^{u:v}$ 作为提示（Prompt $z^p$），剩下的部分作为扩散模型的生成目标。
*   **信息注入设计（重点）**：
    *   对于时长/基频预测器：直接将 Prompt 经过编码器后作为 Key 和 Value，供卷积层查询（Q-K-V Attention）。
    *   对于扩散模型：**避免直接 Attention**。因为直接看 Prompt 会暴露太多声学细节导致模型“照抄”而非“学习”。作者设计了**两级注意力**：先用 $m$ 个随机初始化的 Query 去“浓缩” Prompt 的信息；再让扩散模型的主干（WaveNet）去关注这 $m$ 个浓缩后的结果，最后通过 FiLM 层做仿射变换（缩放和平移特征）。

### 5. **conclusion**
设计核心与实验成就：通过高达4亿（400M）参数量和4.4万小时语音数据的扩展，该系统实现了高表现力、高保真度、强鲁棒性且具备强大零样本合成能力的TTS系统。
- 未来的工作展望：探索一致性模型（Consistency Models）以加速扩散模型的推理，以及引入更大规模的混合语音/歌唱数据进行训练。同时，作者客观地指出了模型可能被滥用于语音克隆的伦理风险（Broader Impacts），展现了严谨的学术责任感。
