### 1. **title** && **abstract**
- 该论文提出了一种基于语言建模的文本到语音（TTS）合成新方法，称为 **VALL-E**。
- **方法：**
	- 打破了传统TTS基于连续信号回归的范式，将语音合成视为一种**条件语言建模任务**。
	- 模型利用现成的神经音频编解码器提取**离散代码**，并利用高达6万小时的英语语音数据进行预训练。

>[!information]
>1. **语言建模**：用离散 token 表示语音，用概率模型建模序列生成
>2. **条件化**：生成过程严格受控于输入文本和参考音频，实现零样本（zero-shot）语音克隆


- **结果**：
	- VALL-E 涌现出了强大的**上下文学习能力（In-context learning）**，仅需提供未知说话人3秒的注册录音作为“声学提示（acoustic prompt）”，即可实现高质量的零样本（Zero-Shot）个性化语音合成，同时还能保留提示音频中的环境声学特征与说话人情感。

>[!hint] Conclusion
>此前的TTS流程多为：音素 $\rightarrow$ 梅尔频谱 $\rightarrow$ 波形
VALL-E 提出了全新的范式：音素 $\rightarrow$ 离散音频代码 $\rightarrow$ 波形

### 2. **intro**
>[!Question]
解决传统级联TTS系统在 zs 场景下的两大瓶颈：
>1. **高度依赖干净数据**：传统模型需要高质量录音室数据，对互联网抓取的大规模含噪数据适应性差，导致模型泛化能力弱。
  >  2. **对未知说话人适应性差**：为未见过的说话人合成语音时，传统方法需要复杂的网络结构工程（如提取说话人向量的Speaker Encoder）或针对特定说话人的微调，无法做到真正轻量化的“即插即用”。


>[!information]
>   **Neural Audio Codec Codes（神经音频编解码器离散代码）**：使用预训练的音频编解码器（文章中采用的是EnCodec）将连续的波形信号离散化后得到的Token序列，替代了传统的梅尔频谱。
>  **In-context Learning（上下文学习能力）**：借用于NLP领域的概念，指模型在不改变自身参数的情况下，通过分析输入序列中的上下文信息，直接完成特定任务（这里指克隆音色并合成目标语音）的能力。

*   **基本原理或核心思想**
    受到 LLM 因数据规模扩大而产生性能飞跃的启发，VALL-E 放弃了传统TTS的“连续信号回归”训练目标，**VALL-E 把语音合成变成了一个“在给定文本音素和声学提示的条件下，预测下一个声学Token”的任务**。
    ==声学一致性==

- 在这 6 万小时的数据中，“噪音”（背景音、口音、不完美的录音环境）实际上起到了**天然的数据增强（Data Augmentation）和正则化（Regularization）** 作用，提高了模型的**泛化能力**。

    
### 3. **method**

>[!Question]
> **这一节到底在解决什么问题**
 >   1. 如何利用音频编解码器（EnCodec）的离散代码特征，进行语音的生成建模？
  >  2. 音频 Token 序列往往极长，且量化器（Quantizer）有 8 层之多，如何设计网络结构，既能预测未知的序列长度，又能保证多层 Token 的生成效率和并行计算？

![[image-193.png| EnCodec 架构]]

**Encodec 在 VALL-E 中的核心作用**：

- **作用一：作为分词器（Tokenizer），将音频离散化（Encoder端）**
    - 在传统的级联 TTS 系统中，我们通常用梅尔频谱图作为中间表示。但在 VALL-E 中，**Encodec 替代了梅尔频谱图**。
    - 利用内部的 **8个残差向量量化器（RVQ，即8个密码本，每个包含1024个词条）**，将音频转化为离散的“声学代码矩阵（Acoustic code matrix）”。
	    - *比如一段 10 秒的音频，会被 Encodec 压缩成一个 750×8 的离散 Token 矩阵。*
- **作用二：作为高保真声音生成器（Decoder端）**
    - 在 VALL-E 的语言模型预测出这些离散的声学代码后，不需要再外接像 HiFi-GAN 那样复杂的声码器。
    - 直接将这些预测出的 Token 矩阵送入 Encodec 的解码器，它就能还原出包含丰富说话人特征和声学环境的高保真 24kHz 波形

>[!hint]
>- **训练阶段**：encodec建立了**全长**的 8 层楼标准答案，模型是在学“如何根据已知推测未知” 。
>- **推理阶段**：只有**开头 3 秒**的 8 层楼（样板间），剩下的楼层完全由模型根据样板间的风格和文字内容，从第 1 层到第 8 层逐层“脑补”出来的 。


[模型基本架构讲解](https://zhuanlan.zhihu.com/p/672852107#:~:text=%E7%9A%84%E6%A8%A1%E5%9E%8B%E7%BB%93%E6%9E%84-,%E5%BD%A2%E5%BC%8F%E5%8C%96%E5%BB%BA%E6%A8%A1%E2%80%94%E2%80%94%E8%AF%AD%E9%9F%B3%E5%B1%82%E9%9D%A2%E7%9A%84%E8%AF%AD%E8%A8%80%E6%A8%A1%E5%9E%8B,-%E6%9C%89%E4%BA%86%E8%AF%AD%E9%9F%B3%E6%95%B0%E6%8D%AE)
- 讲解了模型的输入 $\rightarrow$ 文字、声学特征提取 $\rightarrow$ 预测 $\rightarrow$ 转化为声学波形


![[image-194.png|665]]

- 语音的离散表征，来自Encodec的 Acoustic Tokens ，本质上具有层次结构：靠前的量化器生成的 acoustic tokens 一般表征说话者的身份信息(speaker identity)；靠后的量化器生成的 acoustic tokens 一般表征语音的细节信息。
- speaker identity 的生成质量要求是比较严格的，而细节方面的生成质量则可以有所放松。因此，基于生成质量和合成速度的tradeoff，本文设计了两种不同的训练方式。

- **方式一：自回归方法**
	- 对于第一个量化器生成的acoustic tokens，作者使用自回归的方式进行训练。这种训练方式在生成下一个acoustic tokens时会参考前面生成的结果，生成的质量也会较高，缺点在于acoustic tokens一个一个串行生成，生成的速度较慢。自回归方法的形式化建模是：
	
	$$p(c_{:,1}|x,\tilde{C}_{:,1};\theta_{AR})=\prod_{t=0}^{T}p(c_{t,1}|c_{<t,1},\tilde{c}_{:,1},x;\theta_{AR})$$
	
	- $c_{:,1}$：表示属于第一个代码本（Codebook）的目标声学 token 序列 。
	- $x$：输入的文本音素序列 。
	- $\tilde{c}_{:,1}$：作为声音提示（Acoustic prompt）的 enrollment 语音的第一个量化器 token 序列 。
	    
	- **计算过程**：对于时间步 $t$，模型会根据已生成的历史 token $c_{<t,1}$、音素序列 $x$ 以及声音提示 $\tilde{c}_{:,1}$，逐帧预测当前步的 token $c_{t,1}$ 。


- **方法二：非自回归方法**
	- 对于第二个到第八个量化器的acoustic tokens，作者使用非自回归的方式进行训练。在这种训练方式下，所有的acoustic tokens同时生成，acoustic tokens之间的上下文依赖关系相比于自回归方式要弱，生成质量也会降低，但优点胜在生成速度快。非自回归方法对应的形式化建模是：
	$$p(C_{:,2:8}|x,\tilde{C};\theta_{NAR})=\prod_{j=2}^{8}p(c_{:,j}|C_{:,<j},x,\tilde{C};\theta_{NAR})$$
	
	- 在具体训练某一层（假设为第 $i$ 层，且 $i \in [2,12]$）时，模型需要**结合之前所有层的信息**。VALL-E 会将第 1 层到第 $i-1$ 层的声学 token 分别进行 Embedding 并求和，作为当前层的输入 。具体的特征聚合公式为 ：
	
	$$e_{c_{t,j}}=W_{a}^{j}\odot c_{t,j}$$
	- $W_{a}^{j}$ 是专门为第 $j$ 个 Codebook（代码本/量化器）准备的**声学嵌入权重矩阵（Acoustic Embedding Matrix）**。
	$$e_{c_{t}} = \sum_{j=1}^{i-1}e_{c_{t,j}}$$
	
	- $C_{:,<j}$：表示在当前第 $j$ 层之前所有量化器已经生成的 token 。
	    
	- $\tilde{C}$：完整的声学提示矩阵 。与 AR 阶段不同，NAR 阶段为了更好地约束说话人身份，会将 enrollment 语音全部 8 个量化器的特征累加在一起作为声音提示输入 。
	    
	- **计算过程**：NAR 模型允许序列中的每个 token 在自注意力层中同时关注所有输入 token，从而一次性并行输出当前层的所有时间步，将这部分的时间复杂度从 $\mathcal{O}(T)$ 降低到了 $\mathcal{O}(1)$


- 最终，整体的联合概率即为各部分相乘：
$$p(C|x,\tilde{C};\theta)=p(c_{:,1}|\tilde{C}_{:,1},x;\theta_{AR})\prod_{j=2}^{8}p(c_{:,j}|c_{:,<j},x,\tilde{C};\theta_{NAR})$$

| **特征**        | **训练阶段（Training）**                         | **推理阶段（Inference）**                                           |
| ------------- | ------------------------------------------ | ------------------------------------------------------- |
| **Prompt 构造** | **隐式的。** 长序列中的前文自动作为后文的 Prompt 。 **显式的**。必须手动拼接 3 秒参考音频和转写文本 。（输入的3秒音频 + 需要进行tts任务的text） +  +  +  +  +  +  |
| **AR 工作流**    | **并行训练**。利用真实的下一帧作为标签 。                    | **逐帧预测**。利用上一                                                 |
| **NAR 工作流**   | **随机抽样单层预测**。每步只训练其中一层（2-8 层） 。            | **顺序逐层预测*                                                     |
| **解码策略**      | N/A (计算 Loss)                              |                                                               |
| **上下文利用**     | 学习如何维持一致性。                                                                                                 |


### 4. **experiment**

>[!question]
> 为什么 VALL-E 是半监督训练的？

- **第一步：训练 ASR 模型**  
    作者先用一个很小的、只有 960 小时的**带人工标注**的开源数据集（LibriSpeech），训练了一个**语音识别模型（ASR）**。这个 ASR 就像一个速记员。
    
- **第二步：机器全自动听写（生成伪标签 Pseudo-labels）**  
    作者把那 6 万小时“只有声音没有字幕”的音频，全部丢给这个 ASR 速记员。让 ASR 自动把这 6 万小时的音频全部“听写”成文本（音素）。
    
- **第三步：组合成 VALL-E 的训练集**  
    现在，原本没有标注的 6 万小时音频，就有了对应的文字了，虽然这些文字是机器自动识别的，肯定会有听错的错别字（学术上叫 Noisy transcriptions，噪声标签）。作者就把这 **【声音 + 机器听写的文字】** 凑成一对对的训练数据，喂给 VALL-E 去训练。



- **传统连续型 TTS 极度脆弱**：它在做精确的“连续数值回归拟合”，一个错别字就会导致严重的梯度混乱，合成出来的声音全都是杂音。

- **VALL-E 大语言模型极度鲁棒（Robust）**：语言模型最大的特点就是 **“极强的容错能力”**  ，模型能够依靠庞大的统计规律，自动学会“忽略”那些噪音和错误标注，提取出文字和声音之间最本质的对应关系。

### 5. **conclusion**
- 它成功打通了文本语言模型和语音生成模型的底层逻辑， 证明了将语音合成完全转换为跨模态（文本与离散音频码）语言建模任务的可行性，证实了**离散声学特征完全可以替代连续的梅尔频谱**。
- 为未来构建统一的“文本-音频-视觉”多模态通用大模型指明了方向。

**局限性**：
1.  **合成鲁棒性问题：** 因AR自回归模型存在固有的对齐错乱问题，生成语音中偶有漏字、重字或发音不清的情况（这也是传统Transformer TTS常见的痛点）。
2.  **数据覆盖度短板：** 即使拥有6万小时数据，仍未能涵盖所有声音类型（特别是带浓重口音的说话人），同时该数据集多为朗读风格，导致生成风格的多样性仍有提升空间。
3.  **社会伦理风险：** 作者明确指出，仅凭极短音频即可高保真复刻身份的技术可能引发语音欺诈（Spoofing）风险，呼吁建立检测模型并遵守相关的AI伦理原则。




### **🚀帮助理解的例子**
##### 1. AR 模型训练：带“眼罩”的并行填空（负责第 1 层）

- **场景目标**：学会生成第 1 层的核心特征序列 `A, B, C, D, E, F`。
    
- **输入给模型**：一次性塞入带有起点的标准答案 `[Start, A, B, C, D, E]`。
    
- **训练过程（Teacher Forcing）**：老师（Mask 掩码机制）挡住未来的答案，逼迫模型在同一瞬间**并行**做所有的填空题：
    
    - 看到 `[Start]` -> 猜第 1 个字（真实答案：A）
        
    - 看到 `[Start, A]` -> 猜第 2 个字（真实答案：B）
        
    - 看到 `[Start, A, B]` -> 猜第 3 个字（真实答案：C）
        
    - 以此类推……
        
- **批改（Loss）**：模型交卷后，老师把所有位置的猜测结果和真实答案 `[A, B, C, D, E, F]` 放在一起，一次性算总分并纠错。
    

##### 2. NAR 模型训练：随机抽查的“全景”临摹（负责第 2 到 8 层）

- **场景目标**：音频像千层蛋糕一样有 8 层细节，每层都有完整的一长串 Token（假设有 100 个）。
    
- **输入给模型**：今天老师掷骰子，**随机抽查第 4 层**。老师直接把第 1、2、3 层的**真实完美答案**叠加在一起，作为全景线索直接发给模型。
    
- **训练过程（全局可见）**：因为是 NAR（非自回归），模型不再被蒙上眼罩，不需要从左到右慢慢猜。它直接根据前 3 层的完美线索，**一口气“秒交”** 第 4 层所有 100 个位置的猜测结果。
    
- **批改（Loss）**：老师把模型这“一口气”交上来的 100 个预测，和第 4 层真实的 100 个 Token 逐个对比，算分并纠错。
