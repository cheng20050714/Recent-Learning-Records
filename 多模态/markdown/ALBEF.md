### 3. **method**
#### **3.1 Architecture**
![[image-150.png|668]]

**单模态特征提取 (Unimodal Encoders)**
- **Image Encoder** ：位于左下角，采用的是12层的视觉 Transformer（ViT-B/16）转化为 嵌入向量 + cls
- **Text Encoder** ：位于正下方，采用的是前6层的 $BERT_{base}$ 模型 。它同样将输入文本转化为一系列嵌入向量 + cls
- [!] 这两个编码器是完全解耦的，此时图像和文本特征还处在各自独立的特征空间中。 处理方法也是本文核心 ITC
    

**特征融合前的对齐 (Image-Text Contrastive Loss, ITC)**
- **ITC Loss**：在将特征送入多模态编码器之前，ALBEF 首先利用图像和文本的 `[CLS]` token 计算对比损失
- [!] 本部分也需要学习，使 image 和 text 在同一个特征空间对齐，后文详解
- 借鉴 MOCO

**多模态深度融合 (Multimodal Encoder)**
- **网络结构**：一个6层的 Transformer（由 $BERT_{base}$ 的后6层初始化）。多了一个**交叉注意力层** 
- **融合机制**：单模态文本特征输入后，通过交叉注意力机制，在每一层动态地查询并融合来自图像编码器的视觉特征 。
    
- ==**输出任务**==：
    - **ITM (Image-Text Matching)**：判断当前图文是否真正匹配（引入了前面筛选出的 hard negatives，逼迫模型学习细粒度差异）
    - [!] ITC 算出的对比相似度分布被巧妙地用来为寻找“难负例”（即那些语义相近但细节不匹配的困难样本），且不增加任何额外的计算开销 。
        
    - **MLM (Masked Language Modeling)**：遮蔽部分文本，利用图像上下文和剩余文本来预测被遮挡的词
        
**动量蒸馏机制 (Momentum Distillation, MoD)**

- **Momentum Model**：位于最右侧黄底虚线框内。它是基础模型参数的指数移动平均（EMA）版本 。图中蓝色的 `momentum update` 箭头表示基础模型的参数在训练时不断平滑地更新给动量模型 。
    
- **蒸馏作用**：网络爬取的图文对常为noisy data。图中的橙色 `momentum distillation` 箭头表示，在训练基础模型时，我们不完全死板地信任 GT，而是让动量模型生成pseudo-targets作为额外的监督信号


#### **3.2 Pre-training Objectives**
$$\mathcal{L}=\mathcal{L}_{itc}+\mathcal{L}_{mlm}+\mathcal{L}_{itm}$$
- ITC（单模态）负责粗粒度的跨模态对齐并提供高效的难负例样本，而 MLM 和 ITM（多模态）则在此基础上负责细粒度的语义融合与推理。
**ITC**
- 模型首先提取图像和文本的 `[CLS]` 标记嵌入（即 $v_{cls}$ 和 $w_{cls}$），通过线性变换映射到低维（256维）空间，并计算它们的内积相似度 $s=g_{v}(v_{cls})^{\top}g_{w}(w_{cls})$ **（$g_v$ 和 $g_w$ 可学习）**
- **内积是无法衡量的**，对于输入的某一张图像，模型通过 Softmax 函数将 $M+1$ 分数（正样本 与 $M$ 个负样本）压缩成了一个个介于 $0$ 到 $1$ 之间的概率值（即 $p^{i2t}$ 和 $p^{t2i}$）
- 最后通过最小化预测概率和 One-hot 标签之间的交叉熵损失 $\mathcal{L}_{itc}$，模型会被强制拉大正样本与所有负样本之间的相似度差距

**MLM**
- 设 $\hat{T}$ 为被遮蔽的文本，模型预测被遮蔽词汇的概率分布 $p^{msk}(I,\hat{T})$。MLM 的损失 $\mathcal{L}_{mlm}$ 同样是预测概率与真实词汇 One-hot 分布之间的交叉熵：

$$\mathcal{L}_{mlm}=\mathbb{E}_{(I,\hat{T})\sim D}H(y^{msk},p^{msk}(I,\hat{T}))$$
**ITM**
- **作用域与目的**：同样作用于多模态编码器，作为一个二分类任务，预测输入的图像-文本对是否真正匹配
- Loss处理方法同上


- [!] 大白话来讲，就是从多个角度让预测的和one-hot代表的越来越相近，代表多模态的表现越好
- [?] 但是这三个可以直接相加吗？ 为什么直接相加就可以？


#### **3.3 Momentum Distillation**
- 网络爬取的图文数据存在固有的噪声问题，而传统的 One-hot labels 训练机制放大了这一缺陷，它会盲目惩罚模型产生的所有非标注预测，完全无视这些预测在语义上的合理性
- ![[image-151.png]]
- **核心困境**：正样本通常是弱相关的（例如文本包含与图像无关的词，或图像包含文本未描述的实体）。在 ITC 任务中，负样本可能存在表述正确的信息；而在 MLM 任务中，可能存在与 GT 不同的多个合理匹配项

- **解决方案：动量模型 (Momentum Model)**：
    
    - 维护一个由基础模型（单模态和多模态编码器）参数的**指数移动平均 (EMA)** 构成的持续演进的教师网络 。
        
    - 训练基础模型时，让其预测尽可能匹配这个动量模型所输出的分布 。
        
    - [!] **EMA 的本质**：它相当于跨越时间的“专家投票”（时间集成）。它可以作为低通滤波器，过滤掉前线“基础模型”因为脏数据产生的剧烈梯度震荡，提供极其稳定的历史经验 。
        
- **生成伪目标 (Pseudo-targets) 与损失改造**：
    
    - 利用动量模型生成软标签（soft pseudo-targets）作为额外的监督信号 。当模型产生了与网络生硬标注（GT）不同但合理的输出时，将不再受到盲目的惩罚 。
        
    - 数学实现上，通过计算基础模型预测分布 ($p$) 与动量模型生成的伪目标分布 ($q$) 之间的 **KL散度 (KL-divergence)**，将软标签融合进原有的损失函数中 。
        
    - **$ITC_{MoD}$**：
        
        $$\mathcal{L}_{itc}^{mod}=(1-\alpha)\mathcal{L}_{itc}+\frac{\alpha}{2}\mathbb{E}_{(I,T)\sim D}[KL(q^{i2t}(I)||p^{i2t}(I))+KL(q^{t2i}(T)||p^{t2i}(T))]$$
        
    - **$MLM_{MoD}$**：
        
        $$\mathcal{L}_{mlm}^{mod}=(1-\alpha)\mathcal{L}_{mlm}+\alpha\mathbb{E}_{(I,\hat{T})\sim D}KL(q^{msk}(I,\hat{T})||p^{msk}(I,\hat{T}))$$
        
    - [!] 为了保证模型的简洁性，作者在预训练和下游微调任务中，统一将蒸馏权重 $\alpha$ 设定为 0.4 。
        
- [?] **为什么向一个“反应迟钝”的移动平均模型学习？**
    
    - 前线直接接触数据的“学生模型”虽然学得快，但在包含大量错误标签的 Web 数据前极易“迷失方向”。动量教师模型更新慢，但它沉淀了多代的规律，是一个比当前学生更稳定、更客观的“历史经验集合体”。这就形成了一种绝妙的动态博弈：学生负责敏锐探索，教师负责兜底纠偏。

### 5. **conclusion**
- 该研究从互信息最大化（Mutual Information Maximization）的独特视角为ALBEF的有效性提供了坚实的理论依据 。
    
- 论文论证了图像-文本对比学习（ITC）和掩码语言建模（MLM）本质上是在最大化图像-文本对不同视图之间的互信息下界 
    
- 动量蒸馏机制在理论上被创新性地解释为一种数据增强形式，通过语义相似的样本生成新的视图，鼓励模型学习对语义保持变换不变的表示
