### 1. **title** && **abstract**

**Abstract**:
语音包含多种复杂属性（内容、韵律、音色、声学细节等），给生成带来挑战。

本文提出**NaturalSpeech 3**，一种新颖的TTS系统，核心创新包括：
1. ==**FACodec（Factorized Audio Codec）**：使用**因子化向量量化（FVQ）** 将语音波形解耦为内容、韵律、音色和声学细节四个子空间==
2. **因子化扩散模型（Factorized Diffusion Model）**：在各自子空间中根据对应提示生成语音属性

通过**分而治之（Divide-and-Conquer）** 的设计，NaturalSpeech 3能够有效且高效地对具有解耦子空间的复杂语音进行建模。实验表明，该系统在质量、相似度、韵律和可懂度方面均达到SOTA水平，并在扩展到**1B参数**和**200K小时训练数据**后取得更好性能。

### 2. **intro**

#### 研究背景与动机

| 问题           | 说明                          | 影响          |
| ------------ | --------------------------- | ----------- |
| **语音属性复杂耦合** | 语音包含内容、韵律、音色、声学细节等多种属性，相互交织 | 生成复杂，难以精确控制 |
| **现有方法局限性**  | 无论之前的何种方式**难以有效解耦**         | 建模复杂耦合信息困难  |
| **零样本TTS挑战** | 大规模TTS系统在语音质量、相似度和韵律方面仍不理想  | 难以达到人类水平    |

#### **核心思想**
**分而治之（Divide-and-Conquer）**：将复杂语音分解为表示不同属性的子空间，分别建模后再组合。

#### 主要贡献
1. **FACodec**：新颖的神经语音编解码器，使用FVQ将语音波形解耦为内容、韵律、音色和声学细节子空间
2. **因子化扩散模型**：为每个属性子空间设计扩散模型，根据对应提示生成属性
3. **SOTA性能**：在质量、相似度、韵律和可懂度方面超越现有TTS系统，首次在多说话人LibriSpeech数据集上达到人类水平
4. **可扩展性**：通过扩展到1B参数和200K小时数据进一步提升性能

#### 3.2 FACodec：属性分解编解码器

##### 3.2.1 模型架构

![[Pasted image 20260409202354.png]]
**Figure 2**: FACodec框架

| 组件                      | 功能       | 输出       |
| ----------------------- | -------- | -------- |
| **Speech Encoder**      | 提取语音潜在表示 | 预量化潜在向量h |
| **Timbre Extractor**    | 提取全局音色特征 | 音色嵌入h_t  |
| **Content FVQ**         | 量化内容信息   | 内容码z_c   |
| **Prosody FVQ**         | 量化韵律信息   | 韵律码z_p   |
| **Acoustic Detail FVQ** | 量化声学细节   | 细节码z_d   |
| **Speech Decoder**      | 重建语音波形   | 重构语音x̂   |

**关键设计**：
- 使用**因子化向量量化（FVQ）** 替代RVQ，每个属性有独立的量化器
- 时间下采样率：200（16kHz音频，每帧12.5ms）
- 条件层归一化（Conditional Layer Norm）：将韵律、内容、声学细节与音色信息融合

##### 3.2.2 属性解耦技术

直接分解不能保证解耦，FACodec采用四种技术：

| 技术 | 作用 | 实现方式 |
|------|------|----------|
| **信息瓶颈（Information Bottleneck）** | 限制信息容量，强制压缩 | 投影到低维空间（8维）后量化 |
| **监督学习（Supervision）** | 引导属性学习 | 内容：音素标签；韵律：F0预测；音色：说话人分类 |
| **梯度反转（Gradient Reversal Layer, GRL）** | 消除不必要信息 | 作为"反向惩罚机制"防止属性泄露（如在内容空间中检测到音高信息则加大Loss惩罚） |
| **细节Dropout（Detail Dropout）** | 增强解耦能力 | 训练时以概率p随机mask细节码z_d |

> **核心洞察**：解耦需要主动干预而非自然涌现。仅靠重建损失无法自动解耦，必须显式约束（信息瓶颈+监督+GRL+Dropout）。

#### 3.3 因子化扩散模型

##### 3.3.1 模型架构
![[Pasted image 20260409202603.png]]
**Figure 3**: 因子化扩散模型框架

模型包含五个核心模块：
1. **Phoneme Encoder**：编码音素序列
2. **Duration Diffusion + Length Regulator**：生成时长并扩展音素序列
3. **Prosody Diffusion**：生成韵律码
4. **Content Diffusion**：生成内容码
5. **Detail (Acoustic) Diffusion**：生成声学细节码

**生成顺序**（非自回归设计）：
```
文本y → [音素编码] → [时长扩散] → [长度调节] → [韵律扩散] → [内容扩散] → [细节扩散] → 合成属性
```

**关键设计**：
- 时长、韵律、内容、声学细节使用**相同的离散扩散公式**
- 每个模块2-5层共享相同的扩散架构
- **上下文学习 (In-Context Learning)**：生成每一项目标属性时，都将参考语音对应的属性代码作为Prompt喂给模型，指导风格走向
- **音色免建模机制**：模型不负责生成音色，而是直接从参考语音中提取音色h_t并在最后解码时注入，极大降低了学习复杂度

##### 3.3.2 训练细节：两阶段独立训练

**阶段一：训练FACodec（学会完美解耦）**
- **输入**：海量无标注真实语音
- **过程**：将语音编码 → 经过各类FVQ和GRL解耦分离 → 重新解码重构
- **结果**：获得一个参数被完全**冻结(Frozen)**的"超级解剖刀"

**阶段二：训练因子化扩散模型（学会完形填空）**
利用冻结的FACodec为扩散模型制作"标准答案"和"参考提示"：
- **准备数据**：从同一说话人数据中抽取句子A作为目标（提取目标z作为Ground Truth），句子B作为提示（提取参考z作为Prompt）。句子A的文本转化为音素作为条件
- **扩散做题**：对目标z进行掩码(Mask)加噪。模型结合文本条件和Prompt，逐步预测被掩盖的真实z代码
- **关键技巧**：**无分类器引导(Classifier-Free Guidance, CFG)**。训练时以15%的概率随机丢弃Prompt，让模型既能学会"照猫画虎（模仿Prompt）"，也能学会"无中生有（仅靠文本生成）"

#### 3.3.3 扩散公式

**前向过程（加噪）**：
- 使用mask和uniform转移矩阵$Q_t \in R^{(K+1) \times (K+1)}$
- 每个token有三种可能：保持原token / 均匀重采样到任意类别 / 转移到mask token

**反向过程（去噪）**：
- 从完全mask序列$X_T$开始，逐步恢复原始token序列$X_0$
- 优化负对数似然损失：

$$L_{mask} = \mathbb{E}_{t, X^p, C} [-\sum_{i=1}^{N} m_{t,i} \cdot \log(p_\theta(x_i|X_t, X^p, C))]$$

**推理**：
- 采用**置信度采样**策略，优先解码置信度高的token
- 使用**Classifier-Free Guidance（CFG）**增强条件控制

##### 3.3.3 与NaturalSpeech系列的关系

| 特性 | NaturalSpeech | NaturalSpeech 2 | NaturalSpeech 3 |
|------|---------------|-----------------|-----------------|
| **目标** | 单说话人人类水平质量 | 多说话人高质量多样性 | 多说话人人类水平质量 |
| **表示** | 连续VAE | 连续RVQ | **离散FVQ** |
| **生成模型** | VAE | 连续扩散 | **离散扩散** |
| **核心创新** | 端到端高质量合成 | 零样本能力 | **属性解耦与因子化** |

#### 3.4 零样本推断全流程 (Zero-Shot Inference)

假设任务：用参考音频的风格和音色，说出全新的目标文本。

**步骤1：特征提取 (FACodec Encoder)**
- 输入：参考语音（Speech x）
- 输出：音色嵌入 **h_t**（直接送往终点等待），以及参考属性代码 **z_p, z_c, z_d**（作为风格Prompt）

**步骤2：级联生成 (Factorized Diffusion)**
- 输入：目标文本（Text y）
- 过程：文本转音素 → 预测时长对齐 → 结合参考韵律Prompt生成**目标z_p** → 结合参考内容Prompt生成**目标z_c** → 结合参考细节Prompt生成**目标z_d**

**步骤3：终极重构 (FACodec Decoder)**
- 输入：扩散模型生成的全新目标代码 (z_p, z_c, z_d) + 第一步提取的参考音色 (h_t)
- 输出：高保真、高相似度、自然度媲美人类录音的最终合成语音

> **核心洞察**：理解NS3的钥匙在于厘清 **"两组Z"** 的分别：FACodec提取出来的Z代表**旧的风格**（参考组），而Diffusion扩散出来的Z代表**新的灵魂**（目标组）。

#### 3.5 语音属性操控

得益于因子化设计，NaturalSpeech 3支持灵活的语音属性操控：

| 操控类型 | 说明 | 示例 |
|----------|------|------|
| **音色控制** | 使用不同语音的音色提示 | 用A的音色说B的话 |
| **韵律调节** | 单独调整语速而不改变音色 | 加快语速但保持原音色 |
| **属性组合** | 组合不同来源的属性 | A的音色 + B的韵律 + C的语速 |

### 4. **experiment**

**数据集**：
- **LibriSpeech**：60K小时16KHz未标注语音，约7000个不同说话人

### 5. **conclusion**

#### 5.1 核心贡献总结

1. **FACodec**：首个使用因子化向量量化（FVQ）的神经语音编解码器，将语音解耦为内容、韵律、音色和声学细节四个子空间
2. **因子化扩散模型**：为每个属性子空间设计扩散模型，实现分而治之的语音生成
3. **SOTA性能**：在LibriSpeech和RAVDESS上达到人类水平，在相似度、韵律和可懂度方面全面超越现有方法
4. **可扩展性**：数据和模型规模的增加持续带来性能提升，1B参数+200K小时数据达到最佳效果
5. **属性操控**：支持灵活的语音属性编辑和组合

#### 5.2 与相关工作的对比

| 方法 | 表示方式 | 解耦能力 | 生成方式 | 主要优势 |
|------|----------|----------|----------|----------|
| VALL-E | RVQ | 弱 | 自回归+非自回归 | 零样本能力 |
| NaturalSpeech 2 | 连续RVQ | 弱 | 连续扩散 | 高质量多样性 |
| Voicebox | 连续向量 | 弱 | 流匹配 | 高效推理 |
| **NaturalSpeech 3** | **FVQ** | **强** | **离散扩散** | **属性解耦与操控** |

#### 5.3 局限性与未来方向

**当前局限**：
1. **属性覆盖**：目前仅分解内容、韵律、时长、声学细节和音色，未覆盖能量、背景音等
2. **数据覆盖**：仅在英语LibriVox数据上训练，不支持多语言
3. **FACodec局限**：需要音素转录进行内容监督；解耦能力仅在零样本TTS任务上验证

**未来方向**：
1. 探索更多属性（能量、背景音等）
2. 收集更多样化的多语言数据
3. 探索无监督解耦方法
4. 将FACodec应用于更多任务（零样本语音转换、ASR等）

## 附录：批判性思考与评价

### 方法论评价

**优点**：
- 分而治之的思想清晰，将复杂问题分解为可管理的子问题
- FACodec的解耦设计巧妙，多种技术（信息瓶颈、监督、梯度反转、dropout）协同作用
- 离散扩散模型适合属性生成，配合CFG增强可控性
- 实验设计全面，涵盖质量、相似度、韵律、可懂度多个维度

**可改进之处**：
- 因子化扩散模型中各属性的生成顺序固定，未探索更灵活的生成策略
- 未深入分析不同属性之间的交互影响
- 情感控制等细粒度属性操控未充分探索

### 技术亮点

1. **FVQ（Factorized Vector Quantization）**：相比RVQ的分层量化，FVQ的并行属性量化更适合解耦
2. **Detail Dropout**：简单但有效的技术，强制模型在缺少细节时也能重建语音
3. **置信度采样**：针对离散扩散的推理优化，提升生成质量

### 实践价值
